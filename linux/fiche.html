12Scripts bash et automatisationAdministration
bashVariablesBouclescron
#!/usr/bin/env bash set -euo pipefail # arrêt sur erreur, variable non définie, erreur dans un pipe SRC="${1:?usage: $0 dossier}" DEST="/backup/$(date +%F)" mkdir -p "$DEST" for f in "$SRC"/*.log; do [[ -e "$f" ]] || continue gzip -c "$f" > "$DEST/$(basename "$f").gz" done if ! df -h /backup | awk 'NR==2{exit ($5+0 > 90)}'; then echo "Disque presque plein" >&2 ; exit 1 fi echo "OK"
  • Toujours mettre les variables entre guillemets ("$var") ; tester avec shellcheck
  • $? = code retour ; $1 $@ $# = arguments ; [[ ]] = tests ; $(cmd) = substitution
  • Rendre exécutable : chmod +x ; planifier avec cron ou un timer systemd
  • Au-delà de quelques dizaines de lignes ou pour plusieurs serveurs : Ansible (section 15)

  1. Séance 1 : prise en main. Installer les 2 VM, naviguer, man, redirections, pipes, grep / awk sur des journaux

  6. Séance 6 : réseau et SSH. IP statique, DNS, clés SSH, durcissement sshd, tunnel, bastion
  7. Séance 7 : sécurité et sauvegarde. Pare-feu, fail2ban, SELinux (passer en enforcing et résoudre un refus), rsync / restic avec restauration

Auto-évaluation — clique pour voir la réponse

Quelle est la différence entre Linux, une distribution et un shell ?

Linux est le noyau ; une distribution y ajoute outils et paquets ; le shell (bash) est l'interpréteur de commandes.

Quelle commande affiche la version de la distribution ?

cat /etc/os-release (et uname -r pour le noyau).

Quelle est la différence entre apt et dnf ?

apt gère les paquets .deb (Debian, Ubuntu) ; dnf gère les .rpm (RHEL, Rocky, Fedora).

Que signifie le droit 640 ?

Propriétaire : lecture-écriture ; groupe : lecture ; autres : aucun accès.

À quoi sert le bit sticky sur /tmp ?

Seul le propriétaire d'un fichier (ou root) peut le supprimer ou le renommer dans le dossier.

Différence entre lien dur et lien symbolique ?

Le lien dur est un second nom du même inode (même système de fichiers) ; le lien symbolique est un fichier pointant vers un chemin.

Que font >, >>, 2> et | ?

Rediriger en écrasant, en ajoutant, rediriger les erreurs, relier la sortie d'une commande à l'entrée d'une autre.

Comment lire un journal en continu ?

tail -f fichier, ou journalctl -f (journalctl -u service -f pour un service).

Où sont les mots de passe des utilisateurs ?

Sous forme d'empreintes dans /etc/shadow, lisible seulement par root ; /etc/passwd ne contient pas de mots de passe.

Comment donner les droits d'administration à un utilisateur ?

L'ajouter au groupe sudo (Debian) ou wheel (RHEL), ou une règle dans /etc/sudoers.d via visudo.

Comment démarrer un service et l'activer au boot ?

systemctl enable --now nom ; vérifier avec systemctl status nom.

Que faire après avoir modifié un fichier .service ?

systemctl daemon-reload puis redémarrer le service.

Quelle différence entre SIGTERM et SIGKILL ?

SIGTERM (15) demande un arrêt propre ; SIGKILL (9) tue immédiatement sans nettoyage.

Comment planifier une tâche ?

Avec cron (crontab -e) ou un timer systemd (unit .timer associée à un .service).

Comment voir quels ports sont ouverts et par qui ?

ss -tulpn.

Que contient /etc/fstab et quel risque ?

Les montages au démarrage ; une erreur peut bloquer le boot : tester avec mount -a et utiliser nofail pour les disques secondaires.

Pourquoi utiliser LVM ?

Pour redimensionner les volumes à chaud, regrouper des disques et faire des snapshots.

Un disque est plein alors que du est faible : pourquoi ?

Inodes épuisés (df -i) ou fichiers supprimés mais encore ouverts (lsof +L1).

Quelle différence entre ext4 et XFS ?

ext4 : polyvalent et réductible ; XFS : performant sur gros volumes, agrandissable mais non réductible.

Comment sécuriser SSH ?

Clés plutôt que mots de passe, PermitRootLogin no, AllowUsers, fail2ban, pare-feu ; tester sshd -t et garder une seconde session.

Quel pare-feu sur Ubuntu et sur RHEL ?

ufw (Ubuntu) ; firewalld (RHEL) ; tous deux au-dessus de nftables.

Que sont SELinux et AppArmor ?

Des contrôles d'accès obligatoires qui restreignent ce que les processus peuvent faire, même en tant que root.

Que faire quand SELinux bloque une application ?

Lire l'alerte (ausearch, journalctl), corriger le contexte (restorecon) ou un booléen ; ne pas le désactiver.

Que signifie la règle 3-2-1 ?

3 copies, sur 2 supports différents, dont 1 hors site.

Différence entre RPO et RTO ?

RPO : perte de données acceptable ; RTO : délai acceptable de reprise du service.

Pourquoi une réplication n'est-elle pas une sauvegarde ?

Elle réplique aussi les suppressions et corruptions ; il faut des versions et un test de restauration.

Que fait set -euo pipefail dans un script ?

Arrêt sur erreur, sur variable non définie et sur échec dans un pipe.

Que sont IaaS, PaaS et SaaS ?

Niveaux de service cloud : infrastructure (VM), plateforme (exécution d'applications), logiciel complet.

Quelle différence entre conteneur et machine virtuelle ?

Un conteneur partage le noyau de l'hôte (processus isolés) ; une VM embarque son propre système.

Qu'est-ce que l'infrastructure as code ?

Décrire l'infrastructure dans des fichiers versionnés et l'appliquer automatiquement (Terraform, Ansible).

Quelle licence est copyleft fort et lesquelles sont permissives ?

GPL est copyleft fort ; MIT, BSD et Apache 2.0 sont permissives.

Quelle méthode pour dépanner ?

Définir le symptôme, chercher ce qui a changé, lire les journaux, isoler par couche, corriger un point à la fois et documenter.
