Fondamentaux Cmdlets Aide

Concepts fondamentaux

Qu'est-ce que PowerShell ?

  • Shell en ligne de commande + langage de scripting
  • Basé sur .NET — tout est objet
  • Windows PowerShell 5.1 (intégré) vs PowerShell 7+ (cross-platform)
  • ISE (Windows) ou VS Code (recommandé)

Structure d'une cmdlet

  • Format : Verbe-Nom
  • Verbes approuvés : Get, Set, New, Remove, Start, Stop…
  • Exemple : Get-Service, Set-Item
  • Paramètres : -Name, -Path…

Système d'aide

  • Get-Help — affiche l'aide d'une cmdlet
  • Update-Help — met à jour les fichiers d'aide
  • -Full, -Examples, -Online
  • Get-Command — découvrir des cmdlets
  • Get-Member — propriétés/méthodes d'un objet

Alias courants

  • ls / dir → Get-ChildItem
  • cd → Set-Location
  • cls → Clear-Host
  • echo → Write-Output
  • ? → Where-Object

3 Utiliser le pipeline Windows PowerShell 6 modules
Pipeline Objets Filtrage Formatage Export

Le pipeline — cœur de PowerShell

🔑 Concept clé : Contrairement aux shells Unix qui passent du texte, PowerShell passe des objets .NET dans le pipeline. Chaque cmdlet reçoit un objet complet avec ses propriétés et méthodes.

Filtrage — Where-Object

  • Where-Object { $_.Status -eq "Running" }
  • Alias : ? ou where
  • Syntaxe simplifiée : Where-Object Status -eq Running
  • -like, -match, -gt, -lt…

Tri — Sort-Object

  • Sort-Object -Property Name
  • Sort-Object CPU -Descending
  • Tri multi-colonnes : Sort-Object Name, CPU

Sélection — Select-Object

  • Select-Object -Property Name, Status
  • Select-Object -First 5 / -Last 5
  • Select-Object -Unique
  • Propriétés calculées : @{N="Taille";E={$_.Length/1MB}}

Comptage et mesure

  • Measure-Object — count, sum, avg, min, max
  • Group-Object — regrouper par propriété
  • Compare-Object — différences entre deux collections

Formatage de sortie

CmdletUsageQuand l'utiliser
Format-Table (ft)Affichage en tableauPeu de colonnes, comparaison rapide
Format-List (fl)Liste propriété:valeurBeaucoup de propriétés
Format-Wide (fw)Une seule colonne en largeListes de noms
Out-GridViewGrille interactive (GUI)Exploration interactive
Out-FileRediriger vers un fichierSortie texte brute
Export-CsvExporter en CSVImport Excel / traitement
Export-ClixmlSérialisation XMLRéimporter des objets PS
ConvertTo-JsonConvertir en JSONAPIs / Azure
ConvertTo-HtmlGénérer un rapport HTMLRapports lisibles
⚠ Attention : Toujours placer les cmdlets Format-* en dernier dans le pipeline. Elles convertissent les objets en chaînes de formatage — les cmdlets suivantes ne pourront plus travailler sur les propriétés.
# Pipeline complet : filtrer, trier, sélectionner, exporter Get-Process | Where-Object { $_.WorkingSet -gt 100MB } | Sort-Object WorkingSet -Descending | Select-Object Name, CPU, @{N="RAM(MB)";E={[math]::Round($_.WorkingSet/1MB,1)}} | Export-Csv "gros-processus.csv" -NoTypeInformation

Fonctions et paramètres

function Get-DiskSpace { [CmdletBinding()] param( [Parameter(Mandatory)] [string]$ComputerName, [ValidateRange(1,100)] [int]$SeuilAlerteGB = 10 ) Get-CimInstance -ClassName Win32_LogicalDisk -ComputerName $ComputerName | Where-Object { $_.FreeSpace/1GB -lt $SeuilAlerteGB } } # Appel Get-DiskSpace -ComputerName "SRV01" -SeuilAlerteGB 20

Gestion des erreurs

Try / Catch / Finally

  • try { ... } catch { ... } finally { ... }
  • $_.Exception.Message dans le catch
  • -ErrorAction Stop requis pour attraper

-ErrorAction

  • Stop — génère une erreur fatale
  • Continue — défaut, continue
  • SilentlyContinue — ignore silencieusement
  • Inquire — demande à l'utilisateur

Write-* cmdlets

  • Write-Output — vers le pipeline
  • Write-Host — vers l'écran (hors pipeline)
  • Write-Verbose — avec -Verbose
  • Write-Warning — avertissement jaune
  • Write-Error — erreur non-fatale
try { Get-Item "C:\inexistant.txt" -ErrorAction Stop } catch [System.IO.FileNotFoundException] { Write-Warning "Fichier introuvable : $($_.Exception.Message)" } catch { Write-Error "Erreur inattendue : $_" } finally { Write-Verbose "Bloc finally toujours exécuté" }

8 Administrer des ordinateurs distants (Remoting) 3 modules
Remoting WinRM Sessions

PowerShell Remoting (PSRemoting)

🔑 Protocole : PSRemoting utilise WS-Management (WinRM) sur le port 5985 (HTTP) ou 5986 (HTTPS). Prérequis : Enable-PSRemoting sur la cible.

Activation

  • Enable-PSRemoting -Force sur le serveur cible
  • GPO pour le déploiement en masse
  • WinRM doit être démarré

Connexion interactive

  • Enter-PSSession -ComputerName SRV01
  • Exit-PSSession pour quitter
  • -Credential (Get-Credential) pour s'authentifier

Exécution distante (1-to-many)

  • Invoke-Command -ComputerName @("SRV01","SRV02")
  • -ScriptBlock { ... }
  • Exécution parallèle automatique

Sessions persistantes

  • New-PSSession — crée une session
  • Invoke-Command -Session $s
  • Remove-PSSession — ferme la session
  • L'état est conservé entre les commandes
# Exécuter sur plusieurs serveurs simultanément $serveurs = @("SRV01", "SRV02", "SRV03") Invoke-Command -ComputerName $serveurs -ScriptBlock { @{ Serveur = $env:COMPUTERNAME Memoire = [math]::Round((Get-CimInstance Win32_OperatingSystem).FreePhysicalMemory/1MB, 1) Disque = [math]::Round((Get-PSDrive C).Free/1GB, 1) } } # Session persistante — variable d'état conservée $s = New-PSSession -ComputerName "SRV01" Invoke-Command -Session $s { $compteur = 0 } Invoke-Command -Session $s { $compteur++ ; $compteur } # → 1 Remove-PSSession $s

11 Jobs en arrière-plan et tâches planifiées 2 modules
Background Jobs Scheduled Jobs Parallélisme

Jobs en arrière-plan

Jobs locaux

  • Start-Job — démarrer en arrière-plan
  • Get-Job — lister les jobs
  • Receive-Job — récupérer les résultats
  • Wait-Job — attendre la fin
  • Remove-Job — nettoyer

-AsJob (distants)

  • Paramètre disponible sur beaucoup de cmdlets
  • Invoke-Command -AsJob
  • Get-AzVM -AsJob
  • Rend la main immédiatement

ForEach-Object -Parallel (PS 7+)

  • Exécution parallèle dans le pipeline
  • ForEach-Object -Parallel -ThrottleLimit 5
  • Plus rapide que les jobs classiques
  • Limite : portée isolée par thread
# Jobs en parallèle sur plusieurs serveurs $jobs = $serveurs | ForEach-Object { Start-Job -ScriptBlock { param($srv) @{ Serveur=$srv; Ping=(Test-Connection $srv -Count 1 -Quiet) } } -ArgumentList $_ } $jobs | Wait-Job | Receive-Job $jobs | Remove-Job # PS 7+ — ForEach-Object -Parallel (plus élégant) $serveurs | ForEach-Object -Parallel { @{ Serveur=$_; Ping=(Test-Connection $_ -Count 1 -Quiet) } } -ThrottleLimit 10

Tâches planifiées (Scheduled Jobs)

# Créer une tâche planifiée PowerShell $trigger = New-JobTrigger -Daily -At "6:00 AM" $options = New-ScheduledJobOption -WakeToRun -RunElevated Register-ScheduledJob -Name "RapportQuotidien" ` -ScriptBlock { Get-DiskSpace | Export-Csv "C:\Rapports\disque-$(Get-Date -f yyyyMMdd).csv" } ` -Trigger $trigger -ScheduledJobOption $options # Via le planificateur de tâches Windows (schtasks) Get-ScheduledTask -TaskName "RapportQuotidien"

Les 10 pièges les plus fréquents

🚫 1 — Lancer un script sans .\

  • Toujours écrire .\mon-script.ps1
  • Sans .\ PowerShell cherche une cmdlet, pas un fichier

🚫 2 — ExecutionPolicy restrictive

  • Vérifier : Get-ExecutionPolicy -List
  • Corriger : Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

🚫 3 — Format-Table au milieu d'un pipeline

  • Format-* détruit les objets — mettre toujours en dernier
  • Après Format-Table plus de propriétés accessibles

🚫 4 — Guillemets simples vs doubles

  • "$variable" → remplacée ✅
  • '$variable' → texte littéral ❌

🚫 5 — try/catch sans -ErrorAction Stop

  • Les erreurs non-terminantes ne sont pas capturées
  • Toujours ajouter -ErrorAction Stop dans le try

🚫 6 — Variable locale non transmise à distance

  • Dans un Invoke-Command, utiliser $using:maVariable
  • $variable seule est inconnue sur le serveur distant

🚫 7 — Comparer avec = au lieu de -eq

  • = affecte une valeur
  • -eq compare (et -ceq sensible à la casse)

🚫 8 — Index à partir de 0

  • Premier élément : $tableau[0]
  • Dernier élément : $tableau[-1]

🚫 9 — Supprimer sans tester

  • Toujours tester avec -WhatIf d'abord
  • Remove-Item C:\Dossier -Recurse -WhatIf

🚫 10 — Oublier -NoTypeInformation sur Export-Csv

  • Sans ce paramètre, une ligne #TYPE parasite le CSV
  • PowerShell 7 : désactivé par défaut (PS 5.1 : toujours nécessaire)

Routine pour apprendre une commande inconnue

# Étape 1 : découvrir une commande par thème Get-Command -Noun "*dns*" Get-Command -Module ActiveDirectory # Étape 2 : lire la description rapide Get-Help Resolve-DnsName # Étape 3 : voir des exemples concrets Get-Help Resolve-DnsName -Examples # Étape 4 : explorer les propriétés de l'objet retourné Resolve-DnsName "google.com" | Get-Member # Étape 5 : filtrer ce qui vous intéresse Resolve-DnsName "google.com" | Select-Object Name, Type, IPAddress # Étape 6 : tester à petite échelle avant de généraliser Resolve-DnsName "google.com" -WhatIf # si disponible
