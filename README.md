# Certifs — Outil de révision certifications

Révision rapide de certifications éditeurs avec quiz interactifs générés depuis la documentation officielle.

## Certifications disponibles

| Certification | Dossier | Questions | Statut |
|---|---|---|---|
| AWS Cloud Practitioner (CLF-C02) | `aws-clf-c02/` | 350 (7j × 50) | ✅ Prêt |
| GitHub Foundations | `github-foundations/` | — | 🔜 À venir |

## Structure

Chaque dossier de certification contient :
- `index.html` — quiz interactif autonome (aucune dépendance, fonctionne hors-ligne)
- Questions originales écrites depuis la documentation officielle, jamais copiées depuis des dumps

## Utilisation

Ouvrir `index.html` directement dans un navigateur, ou accéder via GitHub Pages :
👉 https://crachdev.github.io/Certifs/aws-clf-c02/
