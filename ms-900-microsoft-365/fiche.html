03

SharePoint Online & OneDrive for Business

D2 · 35 %

SharePoint Online

  • Stockage d'équipe / organisation
  • Intranet (sites de communication)
  • Bibliothèques de documents partagées
  • Lié aux Microsoft 365 Groups et Teams
  • Sites d'équipe + sites hub
  • Quota : 1 TB + 10 GB / licence

OneDrive for Business

  • Stockage personnel (par utilisateur)
  • Synchronisation locale sur PC/Mac
  • Partage avec collègues ou externe
  • Quota : 1 TB par utilisateur
  • Accès depuis mobile et web
  • Enregistrements Teams réunions individuelles
Piège examen SharePoint = collaboration d'équipe. OneDrive = personnel. Teams = canal de communication (les fichiers Teams sont stockés dans SharePoint).

Exchange Online

D2 · 35 %
Définition Exchange Online = service email cloud (hébergé par Microsoft). Outlook = client qui se connecte à Exchange. Pas besoin de serveur Exchange on-premises.

Boîtes aux lettres

  • Boîte utilisateur (par personne)
  • Boîte partagée (ex: support@)
  • Boîte ressource (salle, équipement)
  • Boîte de groupe M365
  • Archivage en ligne (In-Place Archive)

Fonctionnalités clés

  • Calendrier partagé + salle de conf
  • Carnet d'adresses global (GAL)
  • Règles de transport (mail flow rules)
  • Journalisation (compliance)
  • Rétention et eDiscovery

Groupes dans Exchange

  • Liste de distribution (email uniquement)
  • Groupe M365 (email + SharePoint + Teams)
  • Groupe de sécurité (permissions)
  • Groupe dynamique (règles automatiques)
05

Microsoft Defender for Office 365

D3 · 30 %

Plan 1 (Business Premium inclus)

  • Safe Links — réécriture URLs + vérification au clic
  • Safe Attachments — sandbox des pièces jointes
  • Anti-phishing — détection IA
  • Anti-spam amélioré
  • Real-time detections (rapport basique)

Plan 2 (E5 ou add-on)

  • Tout le Plan 1 +
  • Threat Explorer (investigation avancée)
  • Attack Simulator (simulations de phishing)
  • Automated Investigation & Response (AIR)
  • Microsoft Secure Score
Safe Links en détail À la réception : l'URL est réécrite (wrapped) → au clic en temps réel : vérification contre la liste des sites malveillants → si dangereux : page d'avertissement.
Safe Attachments en détail La pièce jointe est ouverte dans un sandbox (environnement isolé) → si comportement malveillant détecté → pièce jointe bloquée ou remplacée. Délai possible.
06

Microsoft Purview

D3 · 30 %

Sensitivity Labels

  • Classification : Public, Interne, Confidentiel, Top Secret
  • Protection : chiffrement, watermark, restrictions
  • Application manuelle ou automatique (auto-labeling)
  • Inclus dans Office + Outlook + Teams + SharePoint
  • E3 = labels manuels · E5 = auto-labeling

DLP — Data Loss Prevention

  • Empêcher le partage de données sensibles
  • Détecte : numéros CB, IBAN, numéros de sécurité sociale
  • Couvre : Exchange, SharePoint, OneDrive, Teams
  • Actions : bloquer, avertir, demander justification

Conformité & Gouvernance

  • eDiscovery : recherche et collecte de preuves
  • Journaux d'audit : qui a fait quoi, quand
  • Rétention : conserver ou supprimer après X ans
  • Compliance Manager : score de conformité RGPD
Rétention vs Suppression Politique de rétention = conserver les données pendant X ans pour des raisons légales. Ce n'est PAS un backup. Les données supprimées par un utilisateur sont conservées mais cachées.

Microsoft Intune & Windows Autopilot

D2 · 35 %

MDM — Mobile Device Management

  • Gère l'appareil entier
  • Effacement à distance (remote wipe)
  • Politiques de sécurité sur l'appareil
  • Inventaire matériel et logiciel
  • Appareils propriété de l'entreprise (COBO)

MAM — Mobile Application Management

  • Gère uniquement les apps M365
  • Protège les données d'entreprise dans les apps
  • Effacement sélectif (données corp uniquement)
  • Pas de contrôle sur l'appareil personnel
  • BYOD friendly — appareils personnels

Windows Autopilot

Principe L'appareil Windows est livré directement à l'employé → premier allumage → connexion au compte M365 → Autopilot configure automatiquement l'appareil (apps, politiques, domaine) → zéro intervention IT.
  • L'OEM enregistre les appareils dans le tenant Autopilot
  • Ou l'IT importe les numéros de série manuellement
  • Profil Autopilot = définit la configuration cible
  • OOBE (Out-Of-Box Experience) personnalisé
  • Inclus avec Microsoft 365 Business Premium / E3 / E5

Pièges classiques MS-900

Distinctions critiques à l'examen
  • SharePoint = stockage d'équipe/intranet · OneDrive = stockage personnel · Teams = canal de collaboration (fichiers → SharePoint)
  • Intune MDM = gère l'appareil entier (effacement complet) · MAM = gère uniquement les apps (effacement sélectif) → BYOD
  • Exchange Online = service email cloud · Outlook = client qui se connecte à Exchange
  • Business Premium = seule licence Business (≤300 users) avec Intune + Defender Plan 1
  • Defender Plan 1 (Safe Links + Safe Attachments) · Plan 2 (+ Attack Simulator + AIR + Threat Explorer)
  • Sensitivity Labels = classification/protection · DLP = empêcher le partage non autorisé → deux outils complémentaires
  • Entra Connect = synchronise AD on-prem → cloud (pas l'inverse)
  • PIM = accès JIT aux rôles admins (élévation temporaire, pas d'accès permanent)
  • Security Defaults = MFA activée par défaut dans les nouveaux tenants · Conditional Access = règles granulaires (Entra P1 requis)
  • Autopilot = provisioning zéro-touch ; l'IT ne touche pas l'appareil · configure depuis le cloud via Intune
