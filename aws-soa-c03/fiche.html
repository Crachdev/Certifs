⚠️ Pièges classiques de l'examen
⚡ Ces points font trébucher le plus de candidats. Mémorisez-les en priorité.
IAM & Permissions
  • Deny explicit TOUJOURS gagne sur Allow
  • SCP ne donne pas de permissions — elles restreignent seulement
  • Root ne peut PAS être restreint par SCPs dans le management account
  • Pas d'accès cross-account sans AssumeRole ET Trust Policy
  • Permission Boundary ≠ SCP — boundary limite l'identité, SCP limite le compte
CloudWatch & Monitoring
  • Métriques EC2 de base = CPU, Network, Status — PAS la mémoire RAM !
  • RAM requiert l'agent CloudWatch custom
  • Alarme Composite peut être ALARM si ses enfants satisfont la règle
  • CloudTrail ≠ temps réel (délai 15 min)
  • EventBridge = quasi temps réel pour les événements AWS
Réseau
  • VPC Peering non-transitif — A↔B et B↔C ≠ A↔C
  • NACL numéros évalués du plus petit au plus grand (100, 200…)
  • NAT Gateway ≠ Bastion — sortant seulement, pas d'accès SSH entrant
  • 5 IPs réservées par subnet (0, 1, 2, 3, dernier)
  • ACM pour CloudFront → certificat OBLIGATOIREMENT en us-east-1
CloudFormation
  • Change Set = prévisualisation seulement, ne déploie pas
  • Drift Detection = détection seulement, pas de correction auto
  • DeletionPolicy: Retain = la ressource reste même si le stack est supprimé
  • StackSets service-managed = nécessite AWS Organizations
  • !Ref sur ressource = ID/ARN · sur paramètre = valeur du paramètre
ASG & HA
  • Health check grace period = délai avant le PREMIER health check
  • Cooldown = délai après scaling avant une nouvelle évaluation
  • Target Tracking scale in ET out automatiquement
  • Multi-AZ RDS = HA (failover), pas de performances supplémentaires
  • Read Replica = performances (lectures), pas de failover auto
S3 & Storage
  • Block Public Access au niveau compte remplace toute policy publique
  • SSE-KMS = coût KMS par requête GET/PUT
  • S3 Standard vs Intelligent-Tiering → monitoring fee sur Intelligent-T.
  • Cross-Region Replication = uniquement les nouveaux objets après activation
  • Presigned URL = expire selon le délai défini (pas la durée de la session)
