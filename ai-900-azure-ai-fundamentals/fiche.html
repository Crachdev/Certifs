Concepts IA & Machine Learning

D1 · 24 %

Hiérarchie IA

À mémoriser IA ⊃ Machine Learning ⊃ Deep Learning (réseaux de neurones)

Apprentissage supervisé

  • Données labellisées (entrée + sortie connue)
  • Régression : valeur numérique (prix, température)
  • Classification : catégorie (chat/chien, spam/non-spam)
  • Exemple : prédire le prix d'une maison

Apprentissage non supervisé

  • Données sans labels
  • Clustering : regrouper des similarités
  • Réduction de dimensionnalité
  • Exemple : segmentation de clients

Apprentissage par renforcement

  • Agent, environnement, récompenses
  • Apprend par essai-erreur
  • Exemple : jeux, robotique

Computer Vision avec Azure

D2 · 18 %

Azure AI Vision (générique)

  • Analyse d'images (objets, scènes, couleurs)
  • OCR : extraction de texte dans images
  • Génération de descriptions d'images
  • Détection d'objets courants
  • Analyse spatiale (personnes, zones)

Custom Vision (personnalisé)

  • Classification d'images custom
  • Détection d'objets spécifiques
  • Entraînement avec vos propres images
  • Export du modèle (Edge, mobile)
  • Itération rapide sur les données

Azure AI Face

FonctionnalitéDescription
DétectionLocalise les visages + attributs (âge estimé, émotion)
VérificationCompare deux visages (même personne ?)

Restriction d'accès Azure AI Face : certaines fonctionnalités (identification, vérification) nécessitent une approbation Microsoft. Accès limité pour des raisons éthiques.

Document Intelligence

Successeur de Form Recognizer. Extrait du texte structuré depuis formulaires, factures, reçus, cartes d'identité. Supporte les modèles pré-entraînés (invoice, receipt, ID document) et les modèles personnalisés.

06

IA Générative & Azure OpenAI Service

D4 · 21 %

openai.com (direct)

  • Service géré par OpenAI
  • Données peuvent sortir du tenant
  • Pas d'intégration Azure AD
  • Pas de conformité Azure

Azure OpenAI Service

  • Déploiement dans votre région Azure
  • Données restent dans votre tenant
  • Intégré Azure AD / RBAC
  • Conformité Microsoft (ISO, SOC2…)

Modèles disponibles

ModèleTypeUsage
GPT-4 / GPT-3.5Texte (LLM)Chat, complétion, résumé, code
DALL-EImageGénération d'images depuis texte
WhisperAudioTranscription vocale
Ada (Embeddings)VecteursRecherche sémantique, RAG

Prompt Engineering

  • System message : définit le rôle et les contraintes de l'IA
  • Few-shot : fournir des exemples dans le prompt
  • Zero-shot : instruction directe sans exemple
  • Chain of thought : demander à l'IA de raisonner étape par étape
  • Copilot = IA intégrée aux apps (M365, GitHub, Edge, Bing)
RAG — Retrieval Augmented Generation Technique combinant une base de données vectorielle (vos documents) avec un LLM. Le modèle génère des réponses fondées sur vos données, réduisant les hallucinations.
07

Azure Machine Learning

D1 · 24 %

Designer (No-code)

  • Pipeline visuel drag & drop
  • Modules préconçus (nettoyage, normalisation, modèles)
  • Idéal pour apprendre le ML
  • Export en pipeline Python

AutoML (Low-code)

  • Essaie automatiquement de nombreux algorithmes
  • Sélectionne le meilleur modèle
  • Supporte : classification, régression, time series
  • Génère du code Python récupérable

Notebooks (Pro-code)

  • Environnement Jupyter intégré
  • Accès aux SDK Python/R
  • Contrôle total sur le pipeline
  • Intégration Git

Déploiement de modèles

Endpoint temps réel

  • Réponse immédiate (ms)
  • REST API accessible en ligne
  • Idéal : prédiction à la demande
  • Facturation à l'appel

Endpoint batch

  • Traitement par lots de données
  • Planifiable (nuit, weekend)
  • Idéal : scoring de gros volumes
  • Coût optimisé

IA Responsable — 6 Principes Microsoft

D5 · 19 %

1. Équité (Fairness)

  • Ne pas discriminer selon genre, race, âge…
  • Données d'entraînement représentatives
  • Tests de biais réguliers

2. Fiabilité & Sécurité

  • Se comporter de manière prévisible
  • Résistant aux attaques adversariales
  • Tests rigoureux avant déploiement

3. Confidentialité

  • Protéger les données personnelles
  • Minimiser la collecte de données
  • Conformité RGPD / réglementations

4. Inclusion

  • Accessible à tous (handicap, langues)
  • Conception universelle
  • Éviter l'exclusion numérique

5. Transparence

  • Expliquer les décisions de l'IA
  • Modèles explicables (XAI)
  • Informer les utilisateurs

6. Responsabilité

  • Les humains restent responsables
  • Supervision humaine des décisions
  • Mécanismes de recours

Azure AI Content Safety

Service de modération de contenu texte et image. Détecte 4 catégories : hate, violence, self_harm, sexual. Chaque catégorie a un niveau de sévérité de 0 à 6.

Pièges classiques AI-900

Confusion fréquente Azure AI Services (APIs prêtes) ≠ Azure Machine Learning (plateforme d'entraînement). L'examen teste souvent cette distinction.
  • OCR simple → Azure AI Vision ; extraction document structuré → Document Intelligence
  • Entraîner un modèle image custom → Custom Vision, pas Azure AI Vision
  • Azure OpenAI ≠ openai.com : les données restent dans votre Azure tenant
  • AutoML choisit automatiquement l'algorithme ; Designer est drag & drop
  • CLU (intentions/entités) est dans Azure AI Language, pas un service séparé
  • Copilot = IA intégrée aux apps M365 (Word, Excel, Teams…), pas un service Azure pur
  • 6 principes IA responsable : Équité, Fiabilité, Confidentialité, Inclusion, Transparence, Responsabilité
  • Endpoint temps réel = prédiction immédiate ; endpoint batch = scoring de gros volumes
  • LLM = Large Language Model (grand modèle de langage), IA générative basée sur transformer
  • RAG = Retrieval Augmented Generation : LLM + base documentaire vectorielle
